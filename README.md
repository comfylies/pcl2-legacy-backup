## 关闭 PCL 更新（旧版）

如果还没有更新到新版本，可以尝试关闭启动器更新：

1. 在启动器本体旁边找到名为 `PCL` 的文件夹。
2. 用记事本打开 `PCL/Setup.ini`，也就是 `$file/PCL/Setup.ini`。
3. 找到 `SystemSystemUpdate`，把它的值改成 `3`：

   ```ini
   SystemSystemUpdate:3
   ```

4. 如果找不到这一项，可以在文件末尾手动添加上述一行并保存。

此方法针对旧版配置，具体效果取决于版本和配置文件状态。
